# Ford Library — S. 249 / Securities Acts Amendments of 1975

Primary-source notes for the Gerald R. Ford Presidential Library's dedicated S. 249 legislative case file.

The Ford Library finding aid lists four digitized folders in Box 25 of the White House Records Office, Legislation Case Files:

1. [S. 249 Securities Act Amendments of 1975 (1)](./01-enrolled-bill-review.md)
2. [S. 249 Securities Act Amendments of 1975 (2)](./02-signing-statement-drafts.md)
3. [S. 249 Securities Act Amendments of 1975 (3)](./03-congressional-reports.md)
4. [S. 249 Securities Act Amendments of 1975 (4)](./04-final-statement-and-enrolled-bill.md)

Finding aid: https://www.fordlibrarymuseum.gov/sites/default/files/finding_aids_pdfs/360.pdf

## Research note

These four folders are the dedicated S. 249 legislative case-file unit. The Library also has later retrospective references to the 1975 amendments (for example, campaign-era summaries), but those are not part of this four-folder enrolled-bill file.

For the argument that the 1975 framework used federal oversight to create a more competitive and interoperable national system, start with folders (1), (2), and (3). Folder (4) is the best source for Ford's final public wording.
